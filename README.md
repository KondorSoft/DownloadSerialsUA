# Кадр

Локальний вебзастосунок для пошуку доступних серій і якостей на UAKINO та UAFLIX і збереження відео на Windows-комп’ютері. Сторінка працює у браузері, а завантаження виконує локальна служба. Застосунок не обходить DRM або інтерактивні перевірки сайтів.

## Запуск на іншому Windows-комп’ютері

Завантажте лише файл **`Кадр — встановити і запустити.bat`** з репозиторію. Потрібні 64-бітна Windows та інтернет під час першого запуску. Батнік завантажує останній реліз програми з GitHub до `%LOCALAPPDATA%\DownloadSerialsUA`, перевіряє його SHA-256, а Python, бібліотеки, FFmpeg та Chromium встановлює у приватну папку програми. Готовий Python, Node.js, Git і обліковий запис GitHub не потрібні. При кожному запуску батнік перевіряє версію релізу: якщо вона нова, оновлює код; якщо та сама, запускає без повторного завантаження. Якщо GitHub тимчасово недоступний, запускається вже встановлена версія.

Перевірена тестова інсталяція займає близько **800 МіБ**. Під час першого встановлення й оновлення тимчасово потрібно більше вільного місця. Відеофайли займають місце окремо у вибраній папці.

## Запуск із вихідного коду

Потрібні Python 3.10+, Microsoft Edge, FFmpeg та ffprobe у `PATH`, Node.js для першого збирання інтерфейсу.

```powershell
cd frontend
npm install
npm run build
cd ..
python -m pip install -r requirements.txt
python backend/launch.py
```

Після збирання інтерфейсу наступні запуски можна робити подвійним кліком на `Запустити Кадр.bat`. Служба відкриє сторінку на `127.0.0.1`; браузерну вкладку можна закрити, не перериваючи завантаження. Закриття вікна служби зупиняє її, а незавершені серії потім можна повторити.

Щоб зібрати батнік після зміни інсталятора, виконайте `python tools/build_one_bat.py` у корені проєкту. GitHub Actions автоматично збирає інтерфейс і публікує реліз із архівом та контрольною сумою після кожного оновлення гілки `main`.

## Використання

1. Вставте HTTPS-посилання на сторінку UAKINO або UAFLIX і натисніть «Пошук».
2. Виберіть озвучення, серії та якість. Застосунок показує повну роздільність кадру, наприклад `1920 × 800`, разом із позначкою `800p`. Розмір до завантаження позначений `≈` і є оцінкою з HLS-плейлиста.
3. За замовчуванням вибрана системна папка «Завантаження». Впишіть інший шлях — він автоматично збережеться для наступних запусків — або натисніть «Огляд» і виберіть папку у Windows. Якщо вибрано кілька серій, оберіть режим «По черзі» чи «Паралельно». Натисніть «Завантажити».
4. Готові MP4 з’являться у підпапці назви та сезону; часткові файли не вважаються готовими. Після успішного завантаження кількох серій у тій самій папці створюється `Сезон.m3u8` у порядку серій.
5. Біля готового файлу в історії є кнопка видалення з диска. Застосунок просить підтвердження та оновлює плейлист сезону. Це остаточне видалення, без Кошика.

Завдання й історія інстальованої версії зберігаються у `%LOCALAPPDATA%\DownloadSerialsUA\data\state.sqlite3`. Субтитри не завантажуються. Якщо структура сайту або доступність потоку зміниться, адаптер може потребувати оновлення.
